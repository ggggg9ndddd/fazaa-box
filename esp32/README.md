# صندوق فزعة — تشغيل ESP32

## القطع والتوصيل

| القطعة | تتوصل بـ |
|---|---|
| سيرفو القسم 1 — سلك الإشارة (برتقالي/أصفر) | **GPIO 18** |
| سيرفو القسم 2 — سلك الإشارة | **GPIO 19** |
| سيرفوهات — السلك الأحمر (+) | **5V من شاحن خارجي (2A أو أكثر)** — مو من ESP32 |
| سيرفوهات — السلك البني/الأسود (−) | **GND الشاحن + GND الـ ESP32 مع بعض** (أرضي مشترك) |
| لوحة الأرقام 4×3 — الصفوف | **GPIO 13, 14, 27, 26** |
| لوحة الأرقام 4×3 — الأعمدة | **GPIO 25, 33, 32** |
| مكثف 1000µF | بين + و − الشاحن، قريب من السيرفوهات |

> ⚠️ لا تشغّل السيرفوهات من منفذ 3.3V أو 5V في الـ ESP32 — بيعيد التشغيل كل ما تحركت.
> الـ LED الأزرق في اللوحة يضيء لما يكون الصندوق متصل بالإنترنت و Firebase.

## الإعداد (مرة وحدة)

1. **حساب للصندوق في Firebase:** Firebase Console ← Authentication ← Users ← **Add user**.
   اكتب إيميل مثل `box@fazza.app` وكلمة مرور قوية، وانسخ **User UID**.
2. **اسمح للحساب يتحكم بالصندوق:** Realtime Database ← Data ← أضف تحت الجذر:
   `devices` ← `<UID>` = `true` (بنفس طريقة `admins`).
3. **Arduino IDE:**
   - ثبّت دعم ESP32: Boards Manager ← ابحث `esp32` (Espressif) ← Install.
   - Library Manager ← ثبّت: **ArduinoJson** (7.x) و **ESP32Servo** و **Keypad** (Mark Stanley).
4. افتح `fazza_box/fazza_box.ino` وعدّل أعلى الملف:
   `WIFI_SSID` و `WIFI_PASSWORD` و `FIREBASE_EMAIL` و `FIREBASE_PASSWORD`.
5. اختر اللوحة **ESP32 Dev Module** والمنفذ، واضغط **Upload**.
6. افتح **Serial Monitor** على سرعة **115200** — لازم تشوف `[WiFi] متصل` وبعدها الموقع يعرض «الصندوق متصل».

## ضبط زاوية القفل
غيّر `LOCKED_ANGLE` و `OPEN_ANGLE` حسب المزلاج في صندوقكم (جرّب 0 و 90 أول، وعدّل).
`OPEN_TIME` = كم ثانية يبقى القسم مفتوح قبل ما يتقفل تلقائياً (الافتراضي 10 ثواني).

## كيف يشتغل
- كل 30 ثانية يكتب `box/lastSeen` (عشان الموقع يعرف إنه متصل).
- كل أداة لها **رمز ثابت** تحدده من لوحة المسؤول ← الأدوات ← تعديل (يُحفظ في `toolCodes`، والصندوق يقرأه من هناك — تغيّره من اللوحة بدون ما تعيد رفع الكود).
- بعد موافقة المسؤول على الإيصال يظهر الرمز للطالب. يكتبه في لوحة الأرقام ثم `#` (و`*` للمسح).
- أول مرة ← استلام ويبدأ وقت الإيجار. نفس الرمز بعد انتهاء المدة ← إرجاع وتُحسب رسوم التأخير، وتصير الأداة متاحة.
- إذا انقطع الواي فاي: الأقفال تبقى مسكّرة، وما ينفّذ أي شي لين يرجع الاتصال.
- لاحظ: لو انطفى الـ ESP32 والقسم مفتوح، السيرفو يبقى مكانه — فخل الإقفال التلقائي قصير.
